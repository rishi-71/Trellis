# Trellis

Trellis is an AI-powered Smart Campus Platform designed to provide
students, faculty, and administrators with a unified digital campus ecosystem.

## Project Structure

- `apps/web` - Next.js web application
- `apps/mobile` - React Native Expo mobile application
- `apps/backend` - Node.js Express backend
- `packages/shared` - Shared types and constants
- `docs` - Project documentation

## Tech Stack

### Web
- Next.js
- React
- Tailwind CSS

### Mobile
- React Native
- Expo

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Storage
- Cloudinary

### Realtime
- Socket.io
